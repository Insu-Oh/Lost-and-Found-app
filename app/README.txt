# Lost and Found App

## Overview

The Lost and Found App is an Android application developed using Java and SQLite.
The app allows users to create lost or found adverts, upload images, and browse existing listings.

This project was developed for an Android mobile application development assessment task.

## Features

- Create lost or found adverts
- Upload an image for each advert
- Save advert information using SQLite database
- Display saved adverts using RecyclerView
- View advert details
- Remove adverts from the list
- Filter adverts by category
- Display advert date information


## Technologies Used

- Java
- Android Studio
- SQLite Database
- RecyclerView
- ConstraintLayout
- Android Intents
